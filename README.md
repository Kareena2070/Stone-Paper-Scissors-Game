# Stone-Paper-Scissors Game

A simple interactive Stone-Paper-Scissors (Rock-Paper-Scissors) game built with HTML, CSS, and JavaScript. Play against the computer, track your score, and enjoy automatic game resets after each match.

## Features
- Play classic Stone-Paper-Scissors against the computer
- Score tracking for both user and computer
- 10-round match limit with automatic reset
- Visual feedback for wins, losses, and draws
- Responsive and user-friendly interface

## How to Play
1. Open `index.html` in your web browser.
2. Click on your choice: Rock, Paper, or Scissors.
3. The computer will randomly select its choice.
4. The result of each round is displayed, and scores are updated.
5. After 10 rounds, the final winner is announced and the game resets automatically.

## Project Structure
```
Stone-Paper-Scissors-Game/
├── index.html        # Main game interface
├── style.css         # Game styling
├── script.js         # Game logic
├── README.md         # Project documentation
```

## Customization
- You can change the number of rounds by editing the `MAX_ROUNDS` variable in `script.js`.
- Update styles in `style.css` to personalize the look and feel.
